<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → wheelio-api GET /customers?q= | free-text search term + returned customer PII cross here |
| rendered list → DOM | customer names/identity numbers render into the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | free-text search + name/identity rendering | medium | mitigate | React auto-escapes all rendered values; no dangerouslySetInnerHTML; the q term is a URLSearchParams value, never interpolated into a path |
| T-03-05 | Information Disclosure | customer PII in list rows | medium | mitigate | Render only; never log rows; no PII in query-string beyond the user-typed search term |
| T-03-06 | Denial of Service (UX) | live-search request per keystroke | low | mitigate | Debounce (~300ms) into the query key so keystrokes do not fan out to one request each |
| T-03-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs this plan |
</threat_model>
