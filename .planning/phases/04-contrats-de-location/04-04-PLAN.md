<objective>
Build the guided rental wizard shell at `/contrats/nouveau` — the phase centerpiece (RENT-05, full version per the explicit user directive "ça prendra le temps qu'il faut"). It is ONE React Hook Form on ONE route with a local `useState` step index (D-05a, research-decided: no Zustand, no XState, zero new packages), four ordered steps (vehicle → customer → terms → departure) that share one in-memory form so back/next never loses data, per-step validation via `trigger()`, and a hand-authored `<WizardProgress>` stepper. Step 1 reuses the fleet list (filtered to available + canOperate), Step 2 reuses the customer search + inline create, Step 3 captures dates + an OPTIONAL deposit, and Step 4 captures departure mileage+fuel ONLY — the clean Phase 4↔5 seam, with a labelled handoff note where Phase 5 slots the full état des lieux.

This plan builds the shell + steps + validation + the finish SEAM (a callback the wizard invokes on the last step). The actual create→(deposit?)→activate multi-call sequence with partial-failure handling is 04-05, which fills that seam.

Purpose: a real user is guided through the entire golden path as ONE continuous flow, not four disconnected screens (success criterion 4).
Output: the wizard/ directory (schema, WizardProgress, four steps, ContractWizard shell) and the filled `nouveau` route.
</objective>
