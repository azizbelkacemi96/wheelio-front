<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored locale pref (localStorage) -> rendered strings | Only a non-sensitive UI preference crosses here |
| translation JSON -> React render | react-i18next escapes; no HTML injection from resource strings |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-i18n-xss | Information Disclosure / Tampering | translation rendering | low | mitigate | interpolation.escapeValue false is safe only because React escapes JSX by default; no translation string is rendered via dangerouslySetInnerHTML, so a tampered resource cannot inject markup. |
| T-01-locale | Tampering | useLocale localStorage | low | accept | Only a locale preference is stored; worst case renders the wrong language. |
</threat_model>
